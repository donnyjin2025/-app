# 📈 K线离线助手

一个专为「飞机上研究K线」设计的手机离线应用（PWA）：**联网时自动下载并增量更新行情数据，存储在手机本地；飞行模式下完全离线可用**，随时打开查看K线图。

## 功能

- **离线存储**：K线数据存入手机 IndexedDB 本地数据库，应用外壳由 Service Worker 缓存，断网后照常打开使用
- **自动更新**：联网状态下打开应用，会自动把所有已下载的数据增量补到最新（只下载缺的部分）
- **数据下载**：任意币安交易对（BTC/ETH/SOL… 或手动输入），周期支持 5分/15分/1小时/4小时/日线/周线，历史范围 1个月 ~ 10年，分批拉取带进度条
- **专业图表**：零依赖 Canvas 蜡烛图，含成交量、MA7/MA25/MA99 均线、最新价标线、十字光标（显示开高低收/涨跌幅/量/均线值）
- **触摸操作**：单指拖动平移、双指捏合缩放、点按查看单根K线详情；同一交易对可在图表页快捷切换周期
- **存储管理**：查看每组数据的根数与时间范围、占用空间，可单独删除

数据源为币安公开行情 API（免密钥、支持浏览器直接跨域请求）。

## 使用方法

### 1. 部署（任选其一）

这是纯静态页面，没有任何构建步骤和后端：

- **GitHub Pages（推荐）**：仓库 Settings → Pages → 选择分支根目录发布，得到一个 `https://xxx.github.io/...` 地址
- **任意静态托管**：Vercel / Netlify / Cloudflare Pages 直接导入即可
- **本地预览**：`python3 -m http.server 8000` 后访问 `http://localhost:8000`

> 注意：Service Worker 要求 HTTPS（或 localhost），所以手机上使用请用上面的托管方式。

### 2. 手机上安装

1. 用手机浏览器（iPhone 用 Safari，安卓用 Chrome）打开部署好的地址
2. 浏览器菜单 → **「添加到主屏幕」**，它就变成一个独立图标的 App
3. **联网时**：选择交易对和周期，点「下载并离线保存」；上飞机前打开一次应用即可自动更新到最新
4. **飞机上**：直接从主屏幕打开，所有已下载数据都能正常查看

### 3. 存储空间参考

每根K线约 50 字节。1 年日线 ≈ 20 KB；1 年 1小时线 ≈ 500 KB；3 年 5分钟线 ≈ 15 MB。手机存储完全无压力。

## 文件结构

```
index.html          页面结构（主页 + 图表页）
style.css           样式（深色主题、移动端优先）
app.js              主逻辑：IndexedDB 存储、币安数据下载、增量更新、页面交互
chart.js            零依赖 Canvas K线图表（蜡烛/成交量/均线/十字光标/手势）
sw.js               Service Worker：缓存应用外壳实现离线打开
manifest.webmanifest PWA 清单（添加到主屏幕）
icons/              应用图标
```

## 已知限制

- 数据源为币安，覆盖加密货币交易对；A股/美股的免费接口普遍不支持浏览器跨域或需要密钥，如需支持可加一个小型代理服务
- 币安 API 在少数网络环境下不可达，应用内置了 4 个备用域名自动重试
