# 📈 K线离线助手

一个专为「飞机上研究行情」设计的手机离线应用（PWA）：**云端每日自动抓取大宗商品、股票、国债收益率、宏观数据；手机联网时一键同步到本地；飞行模式下完全离线可用**。

## 数据覆盖

| 分类 | 内容 | 来源 |
|---|---|---|
| 国际商品 | COMEX金/银/铜、WTI/布伦特原油、天然气、CBOT大豆/玉米/小麦 | Yahoo Finance |
| 国内期货 | 螺纹钢、热卷、铁矿石、沪铜、沪铝、沪金、沪银、原油、PTA、甲醇、豆粕、白糖、棉花、玻璃（主力连续） | 新浪财经 |
| 股票指数 | 上证、沪深300、中证500、深证成指、创业板指、恒生、标普500、纳斯达克、美元指数 | 腾讯行情 / Yahoo |
| 个股 | 贵州茅台、宁德时代、五粮液、苹果、英伟达、特斯拉（可在 catalog.json 自行增删） | 腾讯行情 / Yahoo |
| 国债收益率 | 中国 2/5/10/30 年、美国 2/10/30 年、美债 10-2 利差 | 东方财富 / FRED |
| 宏观数据 | 美国 CPI、失业率、联邦基金利率、非农、M2；中国 CPI、PPI、PMI、M2 | FRED / 东方财富 |
| 加密货币 | 任意币安交易对，5分~周线，手机直连下载（免密钥跨域接口） | 币安 |
| Wind / iFind | 终端导出 CSV 后在应用内导入（日期+开高低收[+量] 或 日期+数值） | 手动导入 |

> **关于 Wind / iFind**：两者是付费终端授权，API 只能在装有终端的授权电脑上调用，云端与手机均无法直连。用「导出 CSV → 应用内导入」的方式即可把终端数据带上飞机。

## 工作原理

```
GitHub Actions（每日两次定时）
  └─ fetch_data.py 按 catalog.json 抓取 → 提交静态 data/*.json
        └─ GitHub Pages 托管应用 + 数据
              └─ 手机 PWA 联网时同步 → IndexedDB 离线存储
                    └─ 飞行模式：Service Worker 提供应用外壳，本地数据照常查看
```

## 部署步骤

1. 仓库 **Settings → Pages** → Source 选择分支根目录，保存
2. **Actions** 页签手动运行一次「每日更新行情与宏观数据」（之后每天自动跑两次：北京时间 5:30 和 17:30）
3. 手机浏览器打开 Pages 地址（iPhone 用 Safari，安卓用 Chrome）
4. 浏览器菜单 → **「添加到主屏幕」**，成为独立图标的 App
5. 联网时在「数据中心」点「全部下载」（或按需单项下载）；**上飞机前打开一次应用即可自动更新全部数据**
6. 飞机上直接从主屏幕打开，随时查看

本地预览：`python3 fetch_data.py && python3 -m http.server 8000`

## 图表功能

- 蜡烛图 + 成交量 + MA7/25/99 均线（K线类数据）
- 折线 + 渐变面积图（收益率与宏观序列）
- 十字光标：开高低收 / 涨跌幅 / 成交量 / 均线值（或 序列值与较前值变化）
- 单指拖动平移、双指捏合缩放、点按查看单根详情；币安数据可在图表页快捷切换周期
- 零依赖 Canvas 实现，无任何外部库，保证离线可用

## 自定义数据清单

编辑 `catalog.json` 增删条目，推送后 Actions 会自动重新抓取。例如添加一只A股：

```json
{ "id": "pingan", "name": "中国平安", "category": "个股", "src": "tencent", "symbol": "sh601318", "start": "2007" }
```

雅虎代码（美股/港股/商品）：`{ "src": "yahoo", "symbol": "0700.HK" }`；FRED 序列：`{ "src": "fred", "series": "DGS5" }`。

## 文件结构

```
index.html / style.css   页面与样式（深色主题、移动端优先）
app.js                   主逻辑：IndexedDB、数据中心同步、币安直连、CSV导入
chart.js                 零依赖 Canvas 图表（蜡烛/折线/均线/十字光标/手势）
sw.js                    Service Worker：离线壳缓存
manifest.webmanifest     PWA 清单
fetch_data.py            云端抓取脚本（仅 Python 标准库）
catalog.json             数据清单（可自行增删）
.github/workflows/       每日定时抓取的 Actions 工作流
data/                    抓取产物（静态 JSON，Actions 自动提交）
```

## 存储空间参考
